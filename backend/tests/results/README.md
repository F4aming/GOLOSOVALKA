Расхождение указано как `число бюллетеней - participant_count` /
`число бюллетеней - vote_count`. Во всех 40 запусках число бюллетеней и оба
счётчика совпали с числом успешно принятых уникальных голосов.

До исправления один контрольный запуск с 20 участниками дал 20 успешных
HTTP-ответов и 20 бюллетеней, но только 2 в `participant_count` и `vote_count`.
Это наблюдение можно использовать как иллюстрацию дефекта, но не как полноценную
статистическую серию исходной реализации: для симметричного сравнения исходную
версию следует испытать по той же матрице из 40 запусков.
